# 幻想鄉就業市場與離校去向回聲簿

## 編輯目標

這批功能不把普通大學的「就業率宣傳頁」換一層東方名詞，而是追問：
幻想鄉裡的工作、雇主、薪資、到班時間與「一個人」本身是否真的能被一個
百分比分類。

公開頁維持三個原則：

1. 離校去向先公開計數規則，不先宣傳結果。
2. 一位畢業生可以同時有多份互相衝突、卻都有效的去向口供。
3. 招聘廣告既要好笑，也必須寫出實際工作、交換方式、最危險的小字和可退出
   條件；角色的麻煩不能被「專業雇主」角色馴化。

因此頁面沒有單一就業率。它提供五種分母（本人、身體、魂魄、登記姓名與
雇主口供）及五種觀測時刻（正午、滿月、彼岸週、被刪除的週三與境界換側）。
八類去向可以重疊，口供總和可以大於分母。這不是圖表錯誤，而是產品本身要
保存的制度摩擦。

## 角色與場所錨點

公開文案為本網站原創，但下列人物／場所關係用作內部一致性錨點：

- 紅魔館：咲夜的時間停止、女僕家政與紅魔館妖精女僕，構成「零分鐘夜班」
  的勞動時間矛盾；蕾米莉亞的命運不能被當成合法錄用承諾。
- 河童工房：河城荷取的工程能力、商業感與臨時拼裝習慣，構成膠帶版本、
  不相容儀表及工具是否成為同事的爭議。
- 三途川／彼岸：小町的渡船工作與映姬的裁決職責，構成死後排隊、銅錢、
  死亡日期及遲到費的制度摩擦。
- 文文。新聞：射命丸文的速度與新聞活動，構成比事件更早的頭條、完整版本
  保存與預先訂正。
- 博麗神社：靈夢的神社、退治、賽錢不足與邊界關係，構成薪資來源不穩及
  「忘記刊過職缺」。
- 香霖堂：霖之助辨識外界物品名稱／用途的能力，構成錯誤但自信的用途命名、
  未售庫存與實物薪資。
- 永遠亭：永琳、鈴仙、月兔與蓬萊人關係，構成不死病友、滿月缺勤、病歷
  交班和不可無限延長的試用期。
- 白玉樓：妖夢的半人半靈與幽幽子的亡靈／食欲，構成人數、座位、宴席與
  春季送達爭議。
- 地靈殿：覺的讀心、戀的無意識、燐與空的職務，分別支持不可寫內容速記、
  缺席痕跡、熱量與「燃料是否還活著」。
- 愛麗絲人偶工房：人偶操控與自主性支持人偶勞動關係、操線責任與遠端
  應徵者分開簽到。
- 普莉茲姆利巴樂團：騷靈音樂不必依靠普通空氣傳播，支持不可聽暴露與
  靜音事故舞臺工作。
- 稗田／慧音／紫：分別負責保存矛盾版本、點名年代及令分母邊界本身不可靠。

## 二十一份職缺的內容模型

`src/data/employment.js` 為唯一內容來源。每份職缺至少包含：

- 穩定 id、招聘代碼、印記；
- 雇主、職名、地區、麻煩類型、時間觀、薪資類型及一至五枚風險印；
- 工作摘要與實際職責；
- 薪資／交換方式；
- 最容易被小字吃掉的條款；
- 一道能暴露制度矛盾的試工題；
- 雇主典型回音。

四張代表廣告使用原創影印海報，其餘職缺使用同一套紙張、印記與分類廣告
系統，避免二十一張高解析圖片拖慢頁面。所有精確文字仍由 HTML 呈現，圖片
不承擔三語內容。

## 可操作流程

1. 使用者按麻煩類型、時間觀與風險印過濾招聘架。
2. `#employment-job-<id>` 打開可分享的完整職缺，不使用不可索引的 modal。
3. 怪歷書保存姓名、學位號、真正經驗、不願跨過的界線、希望結算方式與可
   到班時間。草稿只在本機。
4. 提交後產生五類可爭議初審之一：面談、試工、訂正、相鄰時間線錄用或雙方
   保留拒絕。
5. 應徵者再留下第二版回覆：接受一班、要求訂正、暫認相鄰錄用、保留或拒絕。
6. 去向口供加入本機回聲簿，立即影響目前點名，但不修改基礎 cohort 資料。

本機鍵：

- `tu:employment:draft`
- `tu:employment:applications`
- `tu:employment:attestations`

事件：

- `employment.application.submitted`
- `employment.application.responded`
- `employment.outcome.attested`

三類事件均投影到校務帳本；投遞與回覆派生鴉天狗通知，最近一份投遞／口供
也會成為 BBS 領域貼文。My TU 計入卷宗數，本機資料櫃可匯出／匯入／刪除，
稗田第十二宗案卷則把招聘廣告、分母聽證與既有卒業／校友時間矛盾放到同一
條紅線上。

## 計數方法

基礎 cohort 為 146 位點名對象、174 份非互斥去向狀態。數字不是對現實的
主張，也不是從百分比倒推的宣傳材料；它們只在本網站內形成可重演的制度
模型。

`employmentOutcomeSnapshot(basis, observation)` 分開套用：

- 計數單位造成的分母與類別增減；
- 觀測時刻造成的分母與類別增減；
- 這台裝置留下的口供。

不得把八類去向正規化成 100%，也不得把不同分母的結果做同比。介面必須一直
顯示「不是就業率」與當前兩份方法註記。

## 視覺與來源

使用者提供的黑白紅魔館女僕招聘頁只作為「一張幻想鄉招聘廣告應該像真正被
貼過、影印過、看過」的視覺方向參考；網站沒有重製其構圖、人物姿勢或文字，
也沒有收錄該頁。

四張公開海報於 2026-07-29 使用內建 OpenAI 圖像生成工具為本專案原創生成：

- 紅魔館零分鐘夜班；
- 河童膠帶工房；
- 三途川排隊申訴；
- 鴉天狗預先訂正。

共同要求是黑墨、廉價影印／孔版印刷、老化紙張、歪斜套色、手貼訂正與留給
HTML 文字的空白紙條；明確排除可讀生成文字、logo、水印、精緻概念藝術、
具名藝術家模仿及參考圖的精確構圖。PNG 工具原稿被縮至 760×1188、移除
metadata 並以 WebP quality 76 編碼，每張約 164–248 KiB。
