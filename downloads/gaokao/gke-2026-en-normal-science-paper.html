L011. The paper first reports “North windway permanently repaired,” then corrects it to “kappa tape still counts as temporary.” What does the correction chiefly restore?6 marks

  1. A more cautious tone for “permanent,” without changing the access judgment
  2. The repair status and the standard used to classify it
  3. The tape's material name, without stating whether passage is currently allowed
  4. The publication sequence, without correcting the permanent–temporary distinction

L022. A bamboo notice says: “Do not stop at the second identical meeting point; it is last week's.” What is the soundest reading?6 marks

  1. “Second” means the traveller overshot and should return to the first point
  2. “Last week's” dates the notice and does not affect the point now in view
  3. Because they look identical, treat the later one as a reserve meeting point
  4. Route identification must check both spatial position and associated time

L055. A source reads, “The gate remained but the path was lost; visitors followed the bell.” What does “lost” chiefly mean here?6 marks

  1. The road was lent elsewhere, requiring visitors to wait for its return
  2. The road was destroyed, forcing visitors to navigate by the bell
  3. The road fled its former place but could still be followed by its traces
  4. The road vanished and could no longer be followed

  2. ②③④①: preserve, identify, give the timed correction, then state scope
  3. ④②①③: publish the new information first and identify the error last
  4. ③①②④: name the error and scope before preserving and correcting

  1. Have both sides confirm the name, rules, and an exit each can identify
  2. Let the referee hold the full rules while participants know only the start signal
  3. Set the name and exit first, then write the rules around the opening round

C022. A library book starts flying toward an open window. What is the best first step?5 marks

  1. Move it into an empty display case for observation without yet alerting staff or readers
  2. Close the window first and identify the book later from memory of its cover
  3. Note the call number, alert staff, and close nearby windows

  1. Keep caster and site fixed, but use the spell best suited to each material
  2. Keep caster, spell, distance, and instrument fixed; change only material
  3. Keep spell and instrument fixed, testing each material at its usual site

S022. If the shorter-wavelength guide signal scatters more strongly in mist, what practical effect is likely?7 marks

  1. Nearby brightness falls while scattering concentrates more signal into distant outlines
  2. Mist changes only perceived colour and leaves arrival-direction information unchanged
  3. Both near and far views brighten, so directional judgment improves throughout
  4. The nearby glow brightens while distant direct signal and direction become harder to resolve

S033. A turbine loses output while head remains constant. What should be measured first?7 marks

  1. Compare output with lunar records to see whether both declined together
  2. Increase input flow until output recovers, then infer efficiency from the added flow
  3. Remeasure head and, if unchanged, attribute the loss to measurement error
  4. Measure actual flow and inspect the runner for blockage

S044. When studying full-moon effects on spatial judgment, which comparison is most important?7 marks

  1. Use the same participants on an easier full-moon route to reduce navigation risk
  2. Comparable participants on the same route at a similar time under a non-full moon
  3. Use different participants on another route in non-full-moon daylight for a clear baseline
  4. Repeat the full-moon route with the same participants to estimate average practice effects

  1. Establishing whether forest material succeeds more often than library samples
  2. Determining whether exactly the same casting motions were used each time
  3. Enabling others to obtain equivalent material for an interpretable independent replication
  4. Comparing whether blast brightness correlates with flight speed

S066. A bamboo navigator is accurate by day but drifts toward a fourth lantern at night. What is the best next step?7 marks

  2. Compare mean day and night error and infer forest movement if night error is larger
  3. Increase announcement volume and retest whether the navigator ignored instructions
  4. Retain the night data and designate the fourth lantern as the official night destination
