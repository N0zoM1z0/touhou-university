HD-L011. 未確認の動機を事実化せず、この誤りを最も正確に述べるものは。12 点

問題資料 · 独立条件
【学報 08:10】北風路は通行再開。
【工房メモ 08:06】第三支柱は河童テープ固定。荷重一名、再検査待ち。
【学報訂正 08:32】「通行再開」を削除し「点検員のみ開放」へ。
  1. 08:10の見出しが限定点検状態を一般通行へ拡張した
  2. 工房は08:32まで通報しなかった
  3. 河童テープは必ず15分以内に切れる
  4. 記者が支柱の危険を意図的に隠した
解答: A

解説工房メモは原報より早い。確定できるのは通行範囲の過度な一般化で、動機やテープ寿命ではない。

HD-L022. 掲示を当日実行可能な指示へ書き換えるなら最も完全なのは。12 点

問題資料 · 独立条件
【竹林掲示甲】鐘の後、白兎の足跡を追う。
【掲示乙・裏書】雨後は足跡が逆向き。薬草の香りを基準にする。
当日記録：昨夜雨、09:00無風、09:07薬草香は南東から。
  1. 次の雨で足跡が消えるまで待つ
  2. 鐘の後は足跡方向を避け、無風時の薬草香の源である南東へ進む
  3. 足跡と香りの双方と逆へ進む
  4. 最初の掲示の字が大きいので足跡を追う
解答: B

解説裏書の雨後例外、無風で有効な香り方向、南東という当日記録を合わせる必要がある。

HD-L033. 甲の修辞を残しつつ証拠水準を保つ研究要約はどれか。12 点

問題資料 · 独立条件
甲「門は動かず、道が門を忘れた。」
乙「辰刻、門柱は旧境石の北二丈。巳刻、道の終端は竹林へ接続。」
丙「八雲紫が今朝上機嫌なのは皆知っている。」
  1. 門も道も一切変化していない
  2. 甲は比喩なので乙の測定はすべて無効
  3. 「道が門を忘れた」とは、門柱不動のまま辰・巳間に道路接続が変化したとの操作的表現で、原因は未確定
  4. 紫が上機嫌なので道は必ず従った
解答: C

解説地域の比喩を観察可能な変数へ対応させ、原因を未知として残すのが適切。

HD-M011. 遅延なしで最速の方法と差は。14 点

問題資料 · 独立条件
博麗門→風路駅徒歩6分。12分間隔、始発08:00。乗車11分、駅→工房徒歩5分。08:07門着。全徒歩31分。
  1. 風路、5分早い
  2. 同時
  3. 風路、1分早い
  4. 徒歩、2分早い
解答: D

解説08:13駅着、08:24発、08:35下車、08:40着。徒歩は08:38で2分早い。

八方向弾幕の第n輪は各方向2n+1弾、中心に別途1弾。最初の4輪、重なりも別々に数える。

  4. 176

HD-M033. 5番目を除外後、元平均に対する低下率は。14 点

問題資料 · 独立条件
満月前の案内誤差（度）2,3,3,4,18。5番目は第四灯干渉。
  1. 40%
  2. 50%
  3. 60%
  4. 75%

HD-C011. 最適切な開始処理は。10 点

問題資料 · 独立条件
符札申請：霧の湖東岸、三回、敗者は赤灯で退場。開始前に風向が変わり赤灯は霧で不可視、審判旗は双方に見える。
  1. 最速者に規則を決めさせる
  2. 退路は助言なので開始
  3. 審判旗を共通可視の退場信号へ変更し、双方確認後に開始
  4. 五回へ増加
解答: C

解説現場変更は可能だが、退場信号は識別可能で双方に共有される必要がある。

HD-C022. 成果を残しつつ出所問題を扱う最良の補足は。10 点

問題資料 · 独立条件
魔理沙の火花実験は手順・量・距離完備。素材は「パチュリーの所にある青石」。直近三月に二ロットある。
  1. 素材名を「魔理沙青」にする
  2. 成功結果を全削除
  3. パチュリーの署名のみ
  4. 取得日・ロット識別特徴・保存試料を追記し、ロット別再試験
解答: D

解説手順再現と素材同等性は別。保存試料とロット別再試験で既存結果を保ちつつ差を特定できる。

HD-C033. 三者の要求を同一視せず、対立を実際に扱う案は。10 点

問題資料 · 独立条件
神社・寺・道観が同夜の中央広場を申請。神社は静かな祭儀、寺は公開説法、道観は仙術展示。翌日は妖精市場。
  1. 騒音と撤収要件で時間・区域を分け、共通設備費と未合意点を公開
  2. 市場を中止する
  3. 三者を同じ中心へ同時配置
  4. 抽選し落選側を記録しない
解答: A

解説実行可能な協議は儀礼差、翌日撤収、残る異議を扱う。

42 点

HD-H011. 「紅霧が全郷を同時に覆ったか」の証拠配置は。14 点

問題資料 · 独立条件
甲は異変当夜、人里で赤光のみ。乙は3日後紅魔館、門番交代記録。丙は50年後編集で「全郷同時に紅霧」。
  1. 最も完全な丙のみ
  2. 甲乙を地点別局地記録とし、時刻付き山・湖資料を追加。丙は後世叙述として扱う
  3. 三資料の日付を平均
  4. 甲が赤光のみなので霧は不存在
解答: B

解説全郷同時性には複数地点の時刻資料が必要で、後世総括は代替しない。

HD-H022. 本日の救援図にどう使うか。14 点

問題資料 · 独立条件
竹林図甲は固定井と日替り経路、作成日なし。乙は日付・月相・固定門あり、仮道なし。
  1. 詳細な甲を丸写し
  2. 日付のある乙だけ使う
  3. 乙の日付・月相・固定門を枠に、甲の井を現地確認。甲の年代不明経路は採らない
  4. 二図を各50％で重ねる
解答: C

解説層ごとに信頼度は異なる。固定点は検証でき、条件経路には日付が必要。

HD-H033. 予測・入場回数・人数・同時滞在を混同しない見出しは。14 点

問題資料 · 独立条件
文の予測800、はたて写真の入場印520、主催券610（うち90再入場可）、広場同時容量560。
  1. 券610枚ゆえ同時610人
  2. 容量560なので実数も560
  3. 祭典に800人来場済み
  4. 写真で入場印520件、独立人数とピークは券の重複除去待ち
解答: D

解説直接観察は520件の印。再入場により独立人数とは限らない。
