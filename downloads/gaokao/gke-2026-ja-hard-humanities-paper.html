HD-L011. 未確認の動機を事実化せず、この誤りを最も正確に述べるものは。12 点

問題資料 · 独立条件
【学報 08:10】北風路は通行再開。
【工房メモ 08:06】第三支柱は河童テープ固定。荷重一名、再検査待ち。
【学報訂正 08:32】「通行再開」を削除し「点検員のみ開放」へ。
  1. 一名荷重のメモは河童テープが通常の学生通行にも耐えないと証明する
  2. 08:10の記者は工房が確認済みの支柱故障を意図的に隠した
  3. 08:10の見出しが限定点検状態を一般通行へ拡張した
  4. 08:32の訂正で初めて制限が加わり、それ以前に工房は荷重上限を報告していない

HD-L022. 掲示を当日実行可能な指示へ書き換えるなら最も完全なのは。12 点

問題資料 · 独立条件
【竹林掲示甲】鐘の後、白兎の足跡を追う。
【掲示乙・裏書】雨後は足跡が逆向き。薬草の香りを基準にする。
当日記録：昨夜雨、09:00無風、09:07薬草香は南東から。
  1. 鐘の後は足跡方向を避け、無風時の薬草香の源である南東へ進む
  2. 鐘の後は足跡を追い、南東で香りが消えた時だけ逆へ進む
  3. 鐘の後は足跡と逆へ進む。裏書が香り案内を置き換えたため
  4. 鐘の後は風を待ち、南東の薬草香を運ぶ風向へ進む

HD-L033. 甲の修辞を残しつつ証拠水準を保つ研究要約はどれか。12 点

問題資料 · 独立条件
甲「門は動かず、道が門を忘れた。」
乙「辰刻、門柱は旧境石の北二丈。巳刻、道の終端は竹林へ接続。」
丙「八雲紫が今朝上機嫌なのは皆知っている。」
  1. 「道が門を忘れた」とは紫の気分が道を変えた意で、門柱測定は門を動かしていない証拠
  2. 辰刻に門柱が不動なので、道は巳刻だけ竹林へ接続し、その後必ず戻った
  3. 甲は修辞、乙は測定で証拠種別が異なるため、一つの要約で比較できない
  4. 「道が門を忘れた」とは、門柱不動のまま辰・巳間に道路接続が変化したとの操作的表現で、原因は未確定

HD-C011. 最適切な開始処理は。10 点

問題資料 · 独立条件
符札申請：霧の湖東岸、三回、敗者は赤灯で退場。開始前に風向が変わり赤灯は霧で不可視、審判旗は双方に見える。
  1. 双方に見える審判旗を退場信号へ明示変更し、確認後に開始する
  2. 申請どおり第1回を始め、霧が残れば審判旗を退場信号へ変える
  3. 内陸側へ移動して赤灯を使い、双方の視認性は改めて確認しない
  4. 赤灯を正式出口のまま残し、敗者が見えない時だけ審判が誘導する

HD-C022. 成果を残しつつ出所問題を扱う最良の補足は。10 点

問題資料 · 独立条件
魔理沙の火花実験は手順・量・距離完備。素材は「パチュリーの所にある青石」。直近三月に二ロットある。
  1. 成功回数は残すが素材関連の結論を全削除し、現存試料も使わない
  2. 二ロットを一つの保存試料へ混ぜ、パチュリー所の青石代表として再試験する
  3. 取得日・ロット特徴・保存試料を追記し、ロット別に同手順を再試験する
  4. 二ロットとも通称青石とパチュリーに確認し、署名を原結果へ付す

HD-C033. 三者の要求を同一視せず、対立を実際に扱う案は。10 点

問題資料 · 独立条件
神社・寺・道観が同夜の中央広場を申請。神社は静かな祭儀、寺は公開説法、道観は仙術展示。翌日は妖精市場。
  1. 抽選で一者だけ使用し、他二者は学外へ移して正式記録に残さない
  2. 騒音と撤収要件で時間・区域を分け、共通費と未合意点を公開する
  3. 翌日市場を中止して一夜を確保し、三者へ同じ音量と配置を求める
  4. 申請順に中心を時間分けし、翌日市場の撤収は最後の団体へ任せる

HD-H011. 「紅霧が全郷を同時に覆ったか」の証拠配置は。14 点

問題資料 · 独立条件
甲は異変当夜、人里で赤光のみ。乙は3日後紅魔館、門番交代記録。丙は50年後編集で「全郷同時に紅霧」。
  1. 甲乙の成立日を同じ日付へ換算し、二資料の一致で同時被覆を判定する
  2. 甲は赤光、乙は交代のみで霧と明記せず、丙を唯一の直接証拠とする
  3. 丙の全郷叙述で範囲を定め、甲乙で人里と紅魔館の詳細を補う
  4. 甲乙を二地点の局地記録とし、時刻付き山・湖資料を探す。丙は後世叙述として扱う

HD-H022. 本日の救援図にどう使うか。14 点

問題資料 · 独立条件
竹林図甲は固定井と日替り経路、作成日なし。乙は日付・月相・固定門あり、仮道なし。
  1. 甲の全経路を基図にし、乙の日付と月相を地図隅へ注記する
  2. 乙の全要素だけを使い、日付のない甲の固定井も救援図へ入れない
  3. 乙の日付・月相・固定門を時態枠にし、甲の井は現地確認、年代不明経路は採らない
  4. 二図を重ね、重なる所を可信とし、不一致は詳細な甲を優先する

HD-H033. 予測・入場回数・人数・同時滞在を混同しない見出しは。14 点

問題資料 · 独立条件
文の予測800、はたて写真の入場印520、主催券610（うち90再入場可）、広場同時容量560。
  1. 写真は入場印520件。独立人数とピークは券の重複除去待ち
  2. 容量560、入場印520。ピークは520～560人
  3. 610枚中90枚が再入場可なので独立人数は正確に520人
  4. 予測800、券610枚。少なくとも独立来場者610人
