HD-L011. 未確認の動機を事実化せず、この誤りを最も正確に述べるものは。12 点

問題資料 · 独立条件
【学報 08:10】北風路は通行再開。
【工房メモ 08:06】第三支柱は河童テープ固定。荷重一名、再検査待ち。
【学報訂正 08:32】「通行再開」を削除し「点検員のみ開放」へ。
  1. 08:10の記者は工房が確認済みの支柱故障を意図的に隠した
  2. 08:10の見出しが限定点検状態を一般通行へ拡張した
  3. 08:32の訂正で初めて制限が加わり、それ以前に工房は荷重上限を報告していない
  4. 一名荷重のメモは河童テープが通常の学生通行にも耐えないと証明する

HD-L022. 掲示を当日実行可能な指示へ書き換えるなら最も完全なのは。12 点

問題資料 · 独立条件
【竹林掲示甲】鐘の後、白兎の足跡を追う。
【掲示乙・裏書】雨後は足跡が逆向き。薬草の香りを基準にする。
当日記録：昨夜雨、09:00無風、09:07薬草香は南東から。
  1. 鐘の後は足跡を追い、南東で香りが消えた時だけ逆へ進む
  2. 鐘の後は足跡と逆へ進む。裏書が香り案内を置き換えたため
  3. 鐘の後は風を待ち、南東の薬草香を運ぶ風向へ進む
  4. 鐘の後は足跡方向を避け、無風時の薬草香の源である南東へ進む

HD-L033. 甲の修辞を残しつつ証拠水準を保つ研究要約はどれか。12 点

問題資料 · 独立条件
甲「門は動かず、道が門を忘れた。」
乙「辰刻、門柱は旧境石の北二丈。巳刻、道の終端は竹林へ接続。」
丙「八雲紫が今朝上機嫌なのは皆知っている。」
  1. 「道が門を忘れた」とは、門柱不動のまま辰・巳間に道路接続が変化したとの操作的表現で、原因は未確定
  2. 「道が門を忘れた」とは紫の気分が道を変えた意で、門柱測定は門を動かしていない証拠
  3. 辰刻に門柱が不動なので、道は巳刻だけ竹林へ接続し、その後必ず戻った
  4. 甲は修辞、乙は測定で証拠種別が異なるため、一つの要約で比較できない

HD-C011. 最適切な開始処理は。10 点

問題資料 · 独立条件
符札申請：霧の湖東岸、三回、敗者は赤灯で退場。開始前に風向が変わり赤灯は霧で不可視、審判旗は双方に見える。
  1. 申請どおり第1回を始め、霧が残れば審判旗を退場信号へ変える
  2. 内陸側へ移動して赤灯を使い、双方の視認性は改めて確認しない
  3. 赤灯を正式出口のまま残し、敗者が見えない時だけ審判が誘導する
  4. 双方に見える審判旗を退場信号へ明示変更し、確認後に開始する

HD-C022. 成果を残しつつ出所問題を扱う最良の補足は。10 点

問題資料 · 独立条件
魔理沙の火花実験は手順・量・距離完備。素材は「パチュリーの所にある青石」。直近三月に二ロットある。
  1. 二ロットを一つの保存試料へ混ぜ、パチュリー所の青石代表として再試験する
  2. 取得日・ロット特徴・保存試料を追記し、ロット別に同手順を再試験する
  3. 二ロットとも通称青石とパチュリーに確認し、署名を原結果へ付す
  4. 成功回数は残すが素材関連の結論を全削除し、現存試料も使わない

HD-C033. 三者の要求を同一視せず、対立を実際に扱う案は。10 点

問題資料 · 独立条件
神社・寺・道観が同夜の中央広場を申請。神社は静かな祭儀、寺は公開説法、道観は仙術展示。翌日は妖精市場。
  1. 申請順に中心を時間分けし、翌日市場の撤収は最後の団体へ任せる
  2. 抽選で一者だけ使用し、他二者は学外へ移して正式記録に残さない
  3. 騒音と撤収要件で時間・区域を分け、共通費と未合意点を公開する
  4. 翌日市場を中止して一夜を確保し、三者へ同じ音量と配置を求める

42 点

HD-S011. 次に最も重要な試験は。14 点

問題資料 · 独立条件
水車試験：旧羽根は流量10で出力72,74。新羽根は流量12で91,93。新羽根が高効率と主張。
  1. 同じ流量・落差で両羽根を交互測定し、入出力を同時に測る
  2. 旧羽根も流量12へ上げ、両者の平均出力だけを比べる
  3. 元の流量で各10回追加し、狭い信頼区間から新羽根効率を判定する
  4. 両羽根の出力/流量比を求めるが、落差と入力は統制しない

HD-S022. 「月相が差を造成」の解釈を最も直接脅かすものは。14 点

問題資料 · 独立条件
薬草試験：満月群4.2日(n=8)、非満月5.0日(n=8)。満月は鈴仙、非満月はてゐが測定し、「回復」基準は未校正。
  1. 両群同数でも各8名なので、平均値は比較できない
  2. 測定者と月相が完全に一致し、判定差を月相効果と分離できない
  3. 回復を小数日で示し、判定精度が観察頻度を超えている
  4. 測定者は違うが、平均差0.8日は全ての判定差を上回る

HD-S033. 最も妥当な結論は。14 点

問題資料 · 独立条件
魔法素材甲14/20成功、乙9/10。甲は霧の湖、乙は図書館、術者同じ。
  1. 術者が同じなので主要差は統制され、70%と90%を素材へ直接帰属できる
  2. 23/30を総成功率とし、場所は事後補正する
  3. 乙は現時点で20ポイント高い。各30回まで増やせば素材差を確認できる
  4. 成功率は場所と素材を混同している。両場所内で甲乙を無作為交替する
