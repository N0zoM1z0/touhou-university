LU-L011. 出来事と新聞社の自己物語を同時に訂正する、最小限で十分な文面は。12 点

問題資料 · 独立条件
【文々。新聞 初版06:40】「山門終日閉鎖、全員霧の湖へ」
【山門当直簿06:35】06:30–07:10大型貨物のみ禁止、学生証は通行。
【号外07:05】「本紙の交渉後、山門再開」
【訂正11:50】「終日閉鎖」を「一部規制」へ。号外は未修正。
【風路記録】07:05前後でゲート状態に変化なし。
  1. 07:05前後に変化がなく号外の再開は不成立。したがって当日は一切の山門規制がなかった
  2. 山門は貨物の一部規制。初版の終日閉鎖は誤り。07:05に再開状態変化はなく、本紙が再開を実現したとの号外も成立しない
  3. 山門は大型貨物のみ規制。初版の「全員」を「貨物」へ直す。07:05号外は交渉効果への自己評価で通行案内ではないため、ゲート記録による訂正は不要
  4. 学生証は通行でき初版の範囲は誤り。ゲート変化はなくても、号外の交渉は閉鎖拡大を防いだ成果とみなせる
解答: B

解説誤った範囲と存在しない状態遷移の双方が対象。一語修正では新聞社が作った因果物語が残る。

LU-L022. 現時点で反証に最も耐える結論は。12 点

問題資料 · 独立条件
【人里暦】九日酉刻に霧、戌刻に鐘停止。
【月都式記録】同夜を十日、鐘停止は霧より半刻前。
【慧音講義】里暦は子刻、月都当直簿は酉刻に日付更新。
【鐘楼修理簿】「霧が先」の行は新しい墨で追記。
  1. 新しい墨の追記は鐘楼の事後検証とみなし、人里記録の順序を支持できる
  2. 更新規則で九日と十日は整合する。よって月都記録の鐘停止先行を人里記録より優先する
  3. 日付差は更新規則による。月都の「半刻前」は人里時制への換算時の丸め誤差とみなし、二記録を霧先・鐘後へ統合できる
  4. 日付差は更新規則で説明可能。ただし霧と鐘停止の順序は対立し、後筆の「霧が先」は独立証拠にならない
解答: D

解説制度で説明できる日付差と出来事順序の対立を分離する。追記は争点に依存し、独立に決着させない。

LU-L033. 規程へ新条文を足さずに最も厳密な判定は。12 点

問題資料 · 独立条件
【学則v3.1】欠席＝予定教室へ入らないこと。
【教務補足v3.1b】境界移動時は教員所在空間を教室とする。
【紫の通知】本日の教室は「出席と欠席の間」、教員は元の教壇。
【入退室】学生甲は元教室へ。空間表示は「予定教室ではない」。
  1. v3.1bは教員所在空間を教室とするため出席根拠はあるが、「予定教室」と「教室」の同一性は版上の穴として残る
  2. v3.1bは教員空間を教室と定め、主規程と同じv3.1系列なので、「予定」の完全な操作定義として甲を出席とすべき
  3. 教員が旧教壇にいるので境界移動はなくv3.1b不適用。入退室表示だけで判定する
  4. 主規程の「予定教室」が補足より優先し、空間表示も否定するため甲は欠席
解答: A

解説補足は出席側の操作定義を与えるが、主規程の「予定」という限定を明示的に上書きしない。

LU-M033. 初期出口Aの最終表示は。14 点

問題資料 · 独立条件
竹林三叉路の出口表示は毎日、置換σ=(A B C)で更新される。日次更新を5回終え、今夜の満月精算で交換τ=(B C)を1回適用する。本問の合成はτ∘σ⁵、すなわちσを5回行った後にτを行う。
  1. 判定不能
  2. A
  3. B
  4. C
解答: C

解説σ⁵=σ²なのでA→C、続いてτによりC→Bとなり、最終表示はB。

LU-C011. 現時点で最も妥当な対応順は。10 点

問題資料 · 独立条件
事件：蔵書『七曜逆引』不在。
入館：魔理沙13:02–15:11、アリス14:20–14:48。貸出なし。小悪魔は14:35在架確認。15:20魔理沙箱に同寸青表紙、背は見えず。14:50–15:05西窓封印停止。
  1. 貸出なしと西窓停止から無断窓外搬出を主仮説とし、箱はまだ調べない
  2. 14:35在架確認から先に退館したアリスを除外し、その後の在館者だけ調べる
  3. まず魔理沙箱の青表紙を調べ、同寸なら最有力蔵書として保全し、背の鑑定後に西窓と棚を調べるか決める
  4. 14:35後の棚・西窓痕跡と青い本の背を確認し、在館者へ聞き複数仮説を残す
解答: D

解説時間窓は絞れるが犯人は一意でない。封印停止と不鮮明写真を識別力ある証拠で確かめる。

LU-C022. 規則の種類と情報更新を同時に扱う判定は。10 点

問題資料 · 独立条件
規則：研究飛行は食堂上空禁止。異変対処は最短安全線可。
12:00煙突逆流、妖精が火災誤報。12:03霊夢が上空直行、12:05焼炉と判明、12:07迂回着陸。
見出し「巫女、研究飛行禁止令を公然違反」
  1. 研究飛行禁止は巫女に適用せず、異変例外は実火災を要する。二理由で12:03は合法
  2. 12:03は当時の火災情報で異変対応例外、12:05後は根拠消失、12:07迂回は整合。見出しは任務を誤分類
  3. 誤報でも12:00逆流は実在するが、例外は実際の異変だけを守り善意誤認は含まないため、12:03は事後判明時に遡って違反となる
  4. 12:03に例外が成立したので、その後の全飛行も食堂上空制限を受けない
解答: B

解説判断は当時利用可能な情報と任務区分で評価する。

LU-C033. 制度上最も正確な結論は。10 点

問題資料 · 独立条件
学祭主舞台投票：神奈子4、白蓮3、神子3。信仰儀礼案件は過半数に加え二伝統以上から賛成1票が必要。守矢儀礼のみの案が6対4、賛成は守矢と無宗派2名のみ。
  1. 案は守矢儀礼のみだが章程は投票者属性を問う。賛成六名で二集団を形成できる
  2. 6対4で一般過半を満たし、複数伝統条件は同票時の決定にのみ使う
  3. 多数はあるが複数伝統支持を欠き、本件の構成要件は票数で代替できない
  4. 無宗派二名は守矢でないため、別伝統として数え二伝統支持を満たす
解答: C

解説過半数と伝統横断支持の二重要件で、一方は他方を代替しない。

LU-H011. 最も適切な研究結論は。14 点

問題資料 · 独立条件
【甲・人里】子刻には濃霧、鐘は15分遅れ。
【乙・妖怪山】六回目の風向東転後に霧、風向計は30分毎。
【丙・霧の湖】月像消失8分後に霧。標準消失時刻23:42。
【丁・50年後】全郷が子刻同時に紅霧。
  1. 丙は約23:50、甲は補正で00:15相当の可能性。乙は起点不明で全郷同時性は未証明
  2. 丁の子刻を全郷の共通時基とし、甲乙丙の局地時刻を丁へ合わせて地域差を判断する
  3. 乙は半刻ごと6回なので開始3時間後。開始時刻不明でも系列長から甲丙より精密といえる
  4. 甲は00:15、丙は約23:50。25分差は両記録の時刻精度を超えるので同じ紅霧を否定できる
解答: A

解説各史料を共通時刻へ校正する。乙の起点欠如と丁の後世概括は同時性を補わない。

LU-H022. 再交渉条件は発動したか。最も堅実な処理は。14 点

問題資料 · 独立条件
山の水車は河童運営、守矢が信仰保証、人里が修繕費。70％未満で再交渉。河童76％（終日）、里64％（ピーク2刻）、守矢88％（祭日1刻）。
  1. 三者は別責任を代表するので三値を等加重平均した76%が契約能力。閾値以上なので終結できる
  2. ピーク2刻が70%未満で文言上発動。採樣窓の欠如は違反責任に影響するが発動には影響しない
  3. 終日76%が最長窓で短い観測より優先。契約にピーク保証がないため再交渉は発動しない
  4. 契約に採樣窓がなく三値は直比較不能。共通窓で再測し、補足条項で70%の時間尺度を定める
解答: D

解説争点は信頼者選びでなく閾値の時間尺度欠如。比較可能性を整えてから発動判定する。

LU-H033. この観察資料に合う結論は。14 点

問題資料 · 独立条件
学報研究「公開訂正で信頼上昇」。文紙は訂正12、信頼42→55。はたて紙は訂正2、51→54。同時に文紙は無料配布と人気異変図連載を開始。
  1. 文は訂正10回多く上昇も10点多い。両紙共通の3点時期傾向を差し引けば、訂正1回約1点と推定できる
  2. 文の訂正と信頼は同時上昇したが、無料配布・人気連載・基線差で訂正の独立効果は推定できない
  3. 両紙とも上昇し訂正多い方が大きい。訂正効果の方向は正と支持できるが、大きさは推定不能
  4. はたての3点を無訂正傾向とし、文の残り10点を12訂正へ帰属。無料配布と連載は接触数だけに影響する
解答: B

解説複数施策が同時変化し初期値も異なるため、前後差を訂正だけへ帰属できない。
