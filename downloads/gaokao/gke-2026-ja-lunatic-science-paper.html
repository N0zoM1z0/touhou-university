LU-L011. 出来事と新聞社の自己物語を同時に訂正する、最小限で十分な文面は。12 点

問題資料 · 独立条件
【文々。新聞 初版06:40】「山門終日閉鎖、全員霧の湖へ」
【山門当直簿06:35】06:30–07:10大型貨物のみ禁止、学生証は通行。
【号外07:05】「本紙の交渉後、山門再開」
【訂正11:50】「終日閉鎖」を「一部規制」へ。号外は未修正。
【風路記録】07:05前後でゲート状態に変化なし。
  1. 山門は大型貨物のみ規制。初版の「全員」を「貨物」へ直す。07:05号外は交渉効果への自己評価で通行案内ではないため、ゲート記録による訂正は不要
  2. 学生証は通行でき初版の範囲は誤り。ゲート変化はなくても、号外の交渉は閉鎖拡大を防いだ成果とみなせる
  3. 07:05前後に変化がなく号外の再開は不成立。したがって当日は一切の山門規制がなかった
  4. 山門は貨物の一部規制。初版の終日閉鎖は誤り。07:05に再開状態変化はなく、本紙が再開を実現したとの号外も成立しない

LU-L022. 現時点で反証に最も耐える結論は。12 点

問題資料 · 独立条件
【人里暦】九日酉刻に霧、戌刻に鐘停止。
【月都式記録】同夜を十日、鐘停止は霧より半刻前。
【慧音講義】里暦は子刻、月都当直簿は酉刻に日付更新。
【鐘楼修理簿】「霧が先」の行は新しい墨で追記。
  1. 日付差は更新規則で説明可能。ただし霧と鐘停止の順序は対立し、後筆の「霧が先」は独立証拠にならない
  2. 新しい墨の追記は鐘楼の事後検証とみなし、人里記録の順序を支持できる
  3. 更新規則で九日と十日は整合する。よって月都記録の鐘停止先行を人里記録より優先する
  4. 日付差は更新規則による。月都の「半刻前」は人里時制への換算時の丸め誤差とみなし、二記録を霧先・鐘後へ統合できる

LU-L033. 規程へ新条文を足さずに最も厳密な判定は。12 点

問題資料 · 独立条件
【学則v3.1】欠席＝予定教室へ入らないこと。
【教務補足v3.1b】境界移動時は教員所在空間を教室とする。
【紫の通知】本日の教室は「出席と欠席の間」、教員は元の教壇。
【入退室】学生甲は元教室へ。空間表示は「予定教室ではない」。
  1. 教員が旧教壇にいるので境界移動はなくv3.1b不適用。入退室表示だけで判定する
  2. 主規程の「予定教室」が補足より優先し、空間表示も否定するため甲は欠席
  3. v3.1bは教員所在空間を教室とするため出席根拠はあるが、「予定教室」と「教室」の同一性は版上の穴として残る
  4. v3.1bは教員空間を教室と定め、主規程と同じv3.1系列なので、「予定」の完全な操作定義として甲を出席とすべき

問題資料 · 独立条件

LU-C022. 規則の種類と情報更新を同時に扱う判定は。10 点

問題資料 · 独立条件
規則：研究飛行は食堂上空禁止。異変対処は最短安全線可。
12:00煙突逆流、妖精が火災誤報。12:03霊夢が上空直行、12:05焼炉と判明、12:07迂回着陸。
見出し「巫女、研究飛行禁止令を公然違反」
  1. 誤報でも12:00逆流は実在するが、例外は実際の異変だけを守り善意誤認は含まないため、12:03は事後判明時に遡って違反となる
  2. 12:03に例外が成立したので、その後の全飛行も食堂上空制限を受けない
  3. 研究飛行禁止は巫女に適用せず、異変例外は実火災を要する。二理由で12:03は合法
  4. 12:03は当時の火災情報で異変対応例外、12:05後は根拠消失、12:07迂回は整合。見出しは任務を誤分類

LU-C033. 制度上最も正確な結論は。10 点

問題資料 · 独立条件
学祭主舞台投票：神奈子4、白蓮3、神子3。信仰儀礼案件は過半数に加え二伝統以上から賛成1票が必要。守矢儀礼のみの案が6対4、賛成は守矢と無宗派2名のみ。
  1. 6対4で一般過半を満たし、複数伝統条件は同票時の決定にのみ使う
  2. 多数はあるが複数伝統支持を欠き、本件の構成要件は票数で代替できない
  3. 無宗派二名は守矢でないため、別伝統として数え二伝統支持を満たす
  4. 案は守矢儀礼のみだが章程は投票者属性を問う。賛成六名で二集団を形成できる

LU-S011. 全資料に最も合う診断は。14 点

問題資料 · 独立条件
河童水車：流量10一定、落差5一定、出力80,79,61,60、軸温31,32,48,49。第3刻に回転センサーv2→v3、手動回転記録は不変、羽根に水草。
  1. 流量・落差・手動回転が一定なので実機出力は不変、低下は表示誤差のみ
  2. v2へ戻し、出力回復なら水草を、未回復なら版を排除できる
  3. v3と出力低下が同刻で、手動回転は不変。版が唯一故障で水草は結果
  4. 水草は出力低下と昇温を説明。版は同時変更だが手動回転不変で、感測偏差は別検証する

LU-S022. 薬・月相・順序・自然経過を最も分離する次設計は。14 点

問題資料 · 独立条件
同じ12名、満月夜に薬甲、翌月新月夜に薬乙。甲が速い。全員が甲→乙、病状は時間とともに自然改善。
  1. 両月相内で甲乙を無作為化し、甲→乙/乙→甲も無作為、洗出しと盲検を設ける
  2. 全員甲→乙のまま第二投薬を早め、盲検判定を加えて自然改善と観察偏差を減らす
  3. 患者が薬を選び、月相を無作為割当。薬の好みは解析時に共変量補正する
  4. 患者を二群にし、一群は満月に甲、他群は新月に乙。人数と初期病状を対応させ薬と月相を同時推定する

LU-S033. 「Bの追加成分が大爆発を造成」を最も識別する追試は。14 点

問題資料 · 独立条件
星素材A「霧雨店奥」、B「香霖堂外来箱」、C「パチュリー第七棚」。A,C主峰同、Bは追加峰。爆発半径8.1,11.7,8.0。B測定前に暗場校正なし。
  1. 同じ校正計器でA,B,Cを測り、呪式と順序を統制し、峰高と半径の用量反応から因果を判定する
  2. B追加成分をAとCへ加え、両方が増大すれば十分性と必要性を証明し、除去Bは不要
  3. 校正後再測し、Bの追加成分をA/Cへ加え、除去Bも試す。施術は盲検無作為化
  4. 校正後Bのみを無作為施術で反復し、追加峰と大爆発が共に再現すれば成分の因果作用を判定する
