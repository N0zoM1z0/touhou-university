01 / GKL-01

幻想郷語文

読解・史料表現・告知・報道修辞

36 点

L011. 学報が「北側風路は恒久修理済み」と報じ、翌日「河童テープはなお仮修理」と訂正した。訂正が最も補ったものは何か。6 点

  1. 報道の発表順だけで、恒久と仮の差は直していない
  2. 「恒久」を慎重な語調へ替えたが、通行判断は変えていない
  3. 修理状態と、それに用いた判定基準
  4. 河童テープの素材名だけで、現在の通行可否は示していない

L022. 竹林掲示「同じ集合点を二度目に見ても止まらないこと。先週のものです。」最も妥当な読み方は。6 点

  1. 経路識別では空間的位置と属する時刻を同時に照合する
  2. 「二度目」は通過しすぎを意味するので、最初の集合点へ引き返す
  3. 「先週の」は掲示の更新日だけを示し、目の前の地点には関係しない
  4. 二つは同じ外観なので、後から現れた方を予備集合点とみなす

L033. 研究のフィールドノートに最も適する文はどれか。6 点

  1. 三回目の鐘が小規模異変を起こし、照明故障を生じさせた
  2. 当番によれば昨日はさらに多く消えたので、今日は正常範囲だ
  3. 東側の灯は妖精が消したらしい。彼女らは信用できないからだ
  4. 三回目の鐘の後、東側五灯のうち二灯が消えた

L044. 同じ小規模異変について、推測を事実として扱わない見出しはどれか。6 点

  1. 妖怪の山の工事で全学時計停止、大学が責任を調査
  2. 全学時計停止、原因はなお調査中
  3. 河童は時刻設定の変更を否定、大学は設備問題を除外
  4. 停止は妖怪の山の試運転と一致、工事が唯一の原因か

L055. 史料「門在れど径亡び、客は鈴声に循いて至る」の「亡」に最も近い意味は。6 点

  1. 道が消失し、もはやその経路を辿れなかった
  2. 道は別所へ貸し出され、返却まで通行を待つ必要があった
  3. 道が人為的に壊され、客は鈴を頼りに進んだ
  4. 道が元の場所から逃げたが、痕跡を追うことはできた

L066. 誤った学務速報を追跡可能な訂正にする最も完全な順序は。①影響範囲 ②元見出し保存 ③誤り明示 ④正しい情報と時刻6 点

  1. ③①②④：誤りと影響を先に示し、後から原文保存と訂正を行う
  2. ④①③②：新情報と影響を先に示し、終結後に原文を保存する
  3. ②③④①：原文保存、誤り明示、時刻付き訂正、影響範囲の順
  4. ④②①③：新情報を先に出し、原文保存後、最後に誤りを示す

03 / GKC-03

幻想郷共通常識

規則・学内判断・異変・共同生活

30 点

C011. スペルカード式勝負の開始前に最も欠かせないものは。5 点

  1. 審判が完全な規則を持ち、参加者には開始信号だけ知らせる
  2. 名称と退路だけ先に決め、初回後に弾幕へ合わせて規則を足す
  3. 名称と回数を公表し、終了方法は火力の高い側に委ねる
  4. 双方が名称・規則・各自から見える退路を確認する

C022. 霧の湖図書館で窓へ飛ぶ蔵書を見つけた。最初の対応は。5 点

  1. まず窓を閉め、事後に表紙の記憶から本を特定する
  2. 請求番号を記録し司書へ連絡、近くの窓を閉める
  3. 最寄りの蔵書封印で本を押さえ、後から適合性を確認する
  4. 空の展示箱へ移して単独観察し、司書や利用者にはまだ知らせない

C033. 河童試作機が青い火花を出すが説明紙は「正常は緑」。どうするか。5 点

  1. 操作を止め、現場を保ち、工房当番へ連絡する
  2. 直ちに電源と外装を外し、危険を除いてから元の状態を撮る
  3. 機器を隔離し、正常火花を青へ改記して次の当番を待つ
  4. 青い火花を記録し、低出力で続けて新機能か確認する

C044. 誤解を招く見出しを書いた本人が訂正授業の教員でもある。最も妥当な処理は。5 点

  1. 元見出しと執筆者の立場を示し、信頼性は読者判断に任せる
  2. 事実は訂正するが、個人問題化を避けるため執筆者の立場は伏せる
  3. 公開訂正し、執筆者の利害関係も事例記録へ残す
  4. 学内委員会の審査後、元見出しを痕跡なく更新する

C055. 満月夜に永遠亭外来へ。詳細図で本館直廊は閉鎖。どの経路を選ぶか。5 点

  1. 本館直廊から診療所へ。同じ建物群なら通れると判断する
  2. 満月時の分流に従い、本館から調剤室経由で診療所へ
  3. 昨日の空地で学鐘を待ち、音から診療所の方向を推定する
  4. 四つ目の灯で直廊を迂回。夜間の灯は詳細図より新しいとみなす

C066. 八雲紫が教室を「出席と欠席の間」へ移した。学生がまず確認すべきものは。5 点

  1. 教員が口頭で教室側を指定し、それを規程の代わりにする
  2. 学内ルーターが信号を学内・学外のどちらと判定するか
  3. 授業後の点呼結果を見てから、その結果で教室位置を決める
  4. 規程の教室所在地と出席定義がこの住所を含むか
04 / GKH-04

文系総合

歴史・地理・報道・信仰と公共生活

42 点

H011. 同じ異変の日付が三史料で異なる。最善の歴史研究法は。7 点

  1. 最も遅い史料を除外し、前二史料と日付が合えば戻す
  2. 同じ暦へ換算し、三日付の平均を事件日とする
  3. 成立時期・作者の位置・それぞれの暦法を比較する
  4. 最初に成立した史料を優先し、後世の記憶影響を避ける

H022. 神社・寺・道観が同じ公共行事予算を争う。公共協議を最も示す案は。7 点

  1. 各者の目的・譲れない点・共通設備費・残る異議を公開する
  2. 予想参加者数で配分し、最終告知には採択案だけを載せる
  3. 三者の完成案から抽選し、落選側は共通設備を求めない
  4. 先に均等配分し、三者の異なる目的を同額へ調整させる

H033. 迷いの竹林は日々ずれるが永遠亭表門は比較的安定。地図表現は。7 点

  1. 固定基準点・条件経路を分け、各層の更新時刻を示す
  2. 日々の経路だけを毎日印刷し、固定基準点への過信を避ける
  3. 縮尺と表門を残し、竹林の不確実性は地図下の注記へまとめる
  4. 最新測量の道を実線にし、表門は方向の参考だけにする

H044. 慧音の授業は「発生・記録・記憶を許されたこと」を区別する。関係は。7 点

  1. 長期に修正された公共記憶は当時記録より信頼でき、出来事を裁定できる
  2. 三者の二項が一致すれば、多数決で唯一の出来事を復元できる
  3. 記録と記憶は権力・媒体の選択・喪失の影響を受けうる
  4. 最古の記録が出来事に最も近く、沈黙は不在を示す

H055. 文が速報を優先し、見出しを先に出して後で検証する。最大の制度的危険は。7 点

  1. 読者が後の改題を別の新事件と誤認する可能性
  2. 学内組織が誤報で行動し、訂正しても結果は自動で戻らない
  3. 他紙が元見出しを転載し、初版の紙面形式を保存しない可能性
  4. 執筆者が授業で訂正を説明し、通常の授業時間が減る可能性

H066. 博麗神社の賽銭箱が頻繁に学外へ移る。研究上最も分析力のある問いは。7 点

  1. 赤い容器は他色より元の場所を離れやすいか
  2. 最後に賽銭箱を持った者を、その時点の所有者とみなせるか
  3. 移動は箱自身が始めるか、最後の接触者が運ぶのか
  4. 神社と大学の所有・用途・所在規則がどう衝突するか
