LU-L011. 若要做一則同時更正事件與報社自我敘事的公開訂正，哪一版本最低限度充分？12 分

題目材料 · 獨立條件
【文文。新聞 初版 06:40】「山門全天封閉，所有人改走霧湖。」
【山門值班簿 06:35】06:30–07:10 僅禁大型貨物；學生證通行。
【號外 07:05】「山門已在本報交涉後重開。」
【訂正欄 11:50】將「全天封閉」改作「部分管制」，未修改號外。
【風路紀錄】07:05 前後閘門狀態無變化。
  1. 山門曾有部分貨運管制；初版錯稱全天封閉。07:05 並無「重開」狀態變化，因此號外所稱由本報促成重開亦不成立
  2. 把「所有人」改成「多數人」即可
  3. 只需說明學生其實能通過，不必處理號外
  4. 因為報社後來訂正，所以 07:05 的重開敘事自動成真
答案: A

解析必須同時處理錯誤範圍與不存在的狀態轉換；只改一個量詞仍會保留報社製造的因果敘事。

LU-L022. 目前最能承受反證的結論是？12 分

題目材料 · 獨立條件
【人里曆】第九日酉時起霧，戌時鐘停。
【月都式記錄】同一夜標作第十日；鐘停早於起霧半刻。
【慧音講義抄】里曆換日於子時；月都值班簿換日於酉時。
【鐘樓維修簿】「霧先至」一行以較新的墨補寫。
  1. 月都記錄一定偽造，因為日期比人里快
  2. 換日規則可解釋九日／十日差異；但霧與停鐘先後仍衝突，且「霧先至」補寫不能作獨立證據
  3. 較新的墨代表較準確的觀察
  4. 兩份記錄日期不同，所以不可能描述同一夜
答案: B

解析先把可由制度解釋的日期差與真正的事件次序衝突分開；補寫來源依附於爭議本身，不能打破平手。

LU-L033. 在不替規章補寫新條文的前提下，哪一判讀最嚴謹？12 分

題目材料 · 獨立條件
【校規 v3.1】「缺席」指學生未進入排定教室。
【教務補充 v3.1b】教室因境界移動時，以教師所在空間為準。
【紫的通知】本日教室位於「出席與缺席之間」，教師仍在原講台。
【門禁】學生甲進入原教室；空間標籤顯示「非排定教室」。
  1. 教師沒有移動，表示教室也絕不可能移動
  2. 只看空間標籤，學生甲必然缺席
  3. v3.1b 把教師所在空間指定為教室，故甲有出席依據；但「排定教室」與「教室」是否同義仍是版本漏洞
  4. 紫使用引號，所以所有門禁資料作廢
答案: C

解析補充條文提供有利於出席的操作定義，但主條文的「排定」限定尚未被明確覆蓋；嚴謹答案要保留這個缺口。

LU-M033. 起始出口 A 的最終標籤為何？14 分

題目材料 · 獨立條件
竹林三岔口每天按置換 σ=(A B C) 更新出口標籤。現在已完成五次每日更新，今晚滿月結算時再施加交換 τ=(B C)。本題的合成明定為 τ∘σ⁵：先做五次 σ，再做一次 τ。
  1. A
  2. B
  3. C
  4. 無法判斷
答案: B

解析σ⁵=σ²，故 A→C；再施 τ，C→B，最終標籤為 B。

事件：帕秋莉館藏《七曜逆引》離架。
門禁：魔理沙 13:02 入館，15:11 離館；愛麗絲 14:20–14:48。
借閱簿：無借出。
小惡魔：14:35 見書仍在。
魔理沙材料箱：15:20 被拍到有同尺寸藍封面，但無書脊。
結界：14:50–15:05 西窗封鎖失效。

  2. 立即認定魔理沙偷書並刊登號外

LU-C022. 哪個判讀同時處理規則類型與資訊更新？10 分

題目材料 · 獨立條件
規則：研究飛行不得穿越食堂上空；異變處理可走最短安全線。
12:00 食堂煙囪倒流，妖精誤報為火災；12:03 靈夢自神社直飛食堂上空；12:05 確認只是夜雀烤爐；12:07 她改道降落。
報告標題：「巫女公然違反研究飛行禁令」。

  3. 妖精誤報使煙囪倒流也沒有發生
  4. 12:03 依當時資訊屬異變處理例外；12:05 後例外理由消失，而 12:07 改道與此相容。原標題把任務類型寫錯

LU-H011. 哪個研究結論最恰當？14 分

題目材料 · 獨立條件
【甲・人里】子時紅霧已濃，作者鐘慢一刻。
【乙・妖怪山】「第六次風向轉東後才見紅霧」；風向器每半刻記一次。
【丙・霧湖】月面在水中消失後 8 分鐘見紅霧；當夜月面消失的標準時刻為 23:42。
【丁・五十年後】全鄉於子時同時陷入紅霧。
  1. 丁證明各地正好同時
  2. 丙給出約 23:50 的湖區時點；甲的「子時」校正後可能晚至 00:15。乙缺少起始讀數，無法定位。現有資料不足以證明全鄉同時
  3. 甲與丙相差 10 分，因此一定是不同異變
  4. 乙有六次讀數，所以最精確
答案: B

解析需要把每份史料校正成共同時基；乙缺起點，丁又是晚期概括，都不能補足同時性。

LU-H022. 是否已觸發重談？最穩健的制度處理是？14 分

題目材料 · 獨立條件
山區公共水輪由河童營運、守矢提供信仰擔保、人里支付維修。合約：產能不足 70% 時三方重談。河童表報 76%；人里在用水尖峰量得 64%；守矢只公布祭典日 88%。三方儀表採樣窗分別為全天、尖峰兩刻、祭典一刻。
  1. 直接採最低值 64%，立即認定河童違約
  2. 直接採祭典 88%，不用重談
  3. 合約未定義採樣窗，三數不能直接比較；先以共同時窗重測，同時把「70%」的時間尺度列入補充條款
  4. 把三數平均成 76%，永久結案
答案: C

解析爭議不是只選哪方可信，而是門檻缺少時間尺度。先修正可比性，才能判定是否觸發。

LU-H033. 哪個結論最符合這份觀察資料？14 分

題目材料 · 獨立條件
校報研究聲稱「公開訂正使信任上升」。資料：本學期 Aya 的報紙訂正 12 次，讀者信任由 42 升至 55；Hatate 的刊物訂正 2 次，信任由 51 升至 54。同時 Aya 改用免費派報且連載熱門異變圖。
  1. Hatate 上升較少，所以訂正一定有害
  2. 只要樣本是報紙，就不需要對照
  3. 訂正次數必然造成全部 13 點上升
  4. Aya 的信任上升與訂正增加同時發生，但免費派報與熱門連載是混雜因素；目前只能說相關，不能估計訂正的獨立效果
答案: D

解析多個政策同時改變，兩刊物初始值也不同；不能把前後差全歸於訂正。
