LU-L011. 若要做一則同時更正事件與報社自我敘事的公開訂正，哪一版本最低限度充分？12 分

題目材料 · 獨立條件
【文文。新聞 初版 06:40】「山門全天封閉，所有人改走霧湖。」
【山門值班簿 06:35】06:30–07:10 僅禁大型貨物；學生證通行。
【號外 07:05】「山門已在本報交涉後重開。」
【訂正欄 11:50】將「全天封閉」改作「部分管制」，未修改號外。
【風路紀錄】07:05 前後閘門狀態無變化。
  1. 山門只限制大型貨物；初版應把「所有人」改成「貨運」。07:05 號外屬報社對交涉效果的自我評價，既非通行指示，便不必依閘門紀錄訂正
  2. 學生證一直可通行，故初版的範圍有誤；號外所稱交涉雖無閘門變化，仍可視為預防封閉擴大的成果
  3. 07:05 前後沒有狀態變化，故號外的重開說不成立；也因此可判定當日從未有任何形式的山門管制
  4. 山門曾有部分貨運管制；初版錯稱全天封閉。07:05 並無「重開」狀態變化，因此號外所稱由本報促成重開亦不成立
答案: D

解析必須同時處理錯誤範圍與不存在的狀態轉換；只改一個量詞仍會保留報社製造的因果敘事。

LU-L022. 目前最能承受反證的結論是？12 分

題目材料 · 獨立條件
【人里曆】第九日酉時起霧，戌時鐘停。
【月都式記錄】同一夜標作第十日；鐘停早於起霧半刻。
【慧音講義抄】里曆換日於子時；月都值班簿換日於酉時。
【鐘樓維修簿】「霧先至」一行以較新的墨補寫。
  1. 換日規則可解釋九日／十日差異；但霧與停鐘先後仍衝突，且「霧先至」補寫不能作獨立證據
  2. 補寫採用較新的墨，可視為鐘樓事後查證，足以支持人里記錄的事件順序
  3. 換日規則可把九日與十日對齊；因此月都記錄的停鐘先於起霧應優先於人里記錄
  4. 日期差來自換日規則；事件順序差則可把月都的『早半刻』視作換算到人里時制時的捨入誤差，兩份記錄因此可合成霧先鐘後
答案: A

解析先把可由制度解釋的日期差與真正的事件次序衝突分開；補寫來源依附於爭議本身，不能打破平手。

LU-L033. 在不替規章補寫新條文的前提下，哪一判讀最嚴謹？12 分

題目材料 · 獨立條件
【校規 v3.1】「缺席」指學生未進入排定教室。
【教務補充 v3.1b】教室因境界移動時，以教師所在空間為準。
【紫的通知】本日教室位於「出席與缺席之間」，教師仍在原講台。
【門禁】學生甲進入原教室；空間標籤顯示「非排定教室」。
  1. 教師仍在舊講台，表示教室沒有發生境界移動，v3.1b 不適用，應只依門禁標籤判定
  2. 主條文的「排定教室」優先於補充條文，空間標籤既否定排定身分，甲應判缺席
  3. v3.1b 把教師所在空間指定為教室，故甲有出席依據；但「排定教室」與「教室」是否同義仍是版本漏洞
  4. v3.1b 明定教師空間就是教室，且補充條文與主規同為 v3.1 系列，因此它應被視為對「排定」一詞的完整操作定義，甲必須判出席
答案: C

解析補充條文提供有利於出席的操作定義，但主條文的「排定」限定尚未被明確覆蓋；嚴謹答案要保留這個缺口。

LU-M033. 起始出口 A 的最終標籤為何？14 分

題目材料 · 獨立條件
竹林三岔口每天按置換 σ=(A B C) 更新出口標籤。現在已完成五次每日更新，今晚滿月結算時再施加交換 τ=(B C)。本題的合成明定為 τ∘σ⁵：先做五次 σ，再做一次 τ。
  1. A
  2. B
  3. C
  4. 無法判斷
答案: B

解析σ⁵=σ²，故 A→C；再施 τ，C→B，最終標籤為 B。

LU-C011. 目前最合理的處理順序是？10 分

題目材料 · 獨立條件
事件：帕秋莉館藏《七曜逆引》離架。
門禁：魔理沙 13:02 入館，15:11 離館；愛麗絲 14:20–14:48。
借閱簿：無借出。
小惡魔：14:35 見書仍在。
魔理沙材料箱：15:20 被拍到有同尺寸藍封面，但無書脊。
結界：14:50–15:05 西窗封鎖失效。
  1. 核對 14:35 後的書架、西窗痕跡與藍色書脊，再訪談在場者並保留多個假說

  3. 小惡魔 14:35 見書在架，故排除較早離館的愛麗絲，只調查其後仍在場者

LU-C022. 哪個判讀同時處理規則類型與資訊更新？10 分

題目材料 · 獨立條件
規則：研究飛行不得穿越食堂上空；異變處理可走最短安全線。
12:00 食堂煙囪倒流，妖精誤報為火災；12:03 靈夢自神社直飛食堂上空；12:05 確認只是夜雀烤爐；12:07 她改道降落。
報告標題：「巫女公然違反研究飛行禁令」。
  1. 誤報不改變 12:00 的煙囪倒流；但規章例外只保護實際異變，不保護善意誤認，所以 12:03 從事後查明時即回溯成違規
  2. 12:03 可適用例外；既然例外曾成立，靈夢之後整段航線都不再受食堂上空限制
  3. 研究飛行禁令不適用巫女，但異變例外要求確認真實火災；兩條理由因此同時使 12:03 合法
  4. 12:03 依當時火災資訊可適用異變處理例外；12:05 後理由消失，12:07 改道與此相容；標題誤分類任務
答案: D

解析決策應按當時可得資訊評估，且研究飛行禁令不等同異變處理規則。

LU-S011. 哪個診斷最符合全部資料？14 分

題目材料 · 獨立條件
河童水輪每刻資料：
流量 10,10,10,10；落差 5,5,5,5；輸出 80,79,61,60；軸溫 31,32,48,49。
第三刻起轉速感測器韌體由 v2 升 v3；人工轉數記錄未變；拆檢發現葉輪纏有水草。
  1. 流量與落差固定而人工轉數未變，說明真實機械輸出未變，下降完全是顯示誤差
  2. 先降回 v2；若輸出恢復即可排除水草，若未恢復即可排除韌體
  3. v3 與輸出下降同刻出現；人工轉數未變，故韌體應是唯一故障，水草只是結果
  4. 水草可解釋輸出下降與升溫；韌體同時更換但人工轉數未變，感測偏差應另行驗證
答案: D

解析物理共變量支持阻塞；版本事件仍需 A/B 校驗，但不能單靠時間重合取代機理。

LU-S022. 下一輪最能分開藥物、月相、順序與自然病程的設計是？14 分

題目材料 · 獨立條件
月草藥效研究分兩夜：同 12 名患者，滿月夜服藥甲、次月新月夜服藥乙；結果甲較快。所有患者都先甲後乙，且病程通常隨時間自然改善。
  1. 在兩月相內隨機給甲乙，並隨機安排甲→乙／乙→甲，設洗脫期與盲化判讀
  2. 維持全員甲→乙，但把第二次給藥提前並加入盲化判讀，降低自然改善與觀察偏差
  3. 讓患者選擇藥物，再由研究者把月相隨機分配為滿月或新月；偏好可在分析時作共變量校正
  4. 把患者分成兩組，一組滿月只用甲、另一組新月只用乙；兩組人數與初始病情配對，就可同時估計藥物和月相
答案: A

解析交叉且平衡的因子設計可估計藥物、月相及順序效應；洗脫與盲化處理殘留及判讀偏差。

LU-S033. 哪個後續步驟對「B 的額外成分造成更大爆炸」最具區分力？14 分

題目材料 · 獨立條件
星光材料來源紀錄：樣本 A「霧雨店後架」；B「香霖堂外界箱」；C「帕秋莉第七櫃」。光譜顯示 A、C 主峰相同，B 多一峰；三者在同咒式的爆炸半徑 A=8.1、B=11.7、C=8.0。儀器在測 B 前未做暗場校正。
  1. 在同一已校正儀器上重測 A、B、C，控制咒式與施術順序，再以峰高和爆炸半徑的劑量反應關係判定因果
  2. 把 B 額外成分分別加入 A 與 C；若兩者爆炸都增大，即已證明充分性與必要性，不必再測去除後的 B
  3. 校正後重測；把 B 的額外成分加入 A/C，並測試去除該成分的 B，施術盲化且隨機
  4. 校正後只重測 B；若額外峰與較大爆炸在多次隨機施術中共同重現，即可判定成分具有因果作用
答案: C

解析先排除儀器假峰，再以添加／去除介入檢驗成分的必要性與充分性。
