LU-L011. 若要做一則同時更正事件與報社自我敘事的公開訂正，哪一版本最低限度充分？12 分

題目材料
【文文。新聞 初版 06:40】「山門全天封閉，所有人改走霧湖。」
【山門值班簿 06:35】06:30–07:10 僅禁大型貨物；學生證通行。
【號外 07:05】「山門已在本報交涉後重開。」
【訂正欄 11:50】將「全天封閉」改作「部分管制」，未修改號外。
【風路紀錄】07:05 前後閘門狀態無變化。
  1. 山門曾有部分貨運管制；初版錯稱全天封閉。07:05 並無「重開」狀態變化，因此號外所稱由本報促成重開亦不成立
  2. 把「所有人」改成「多數人」即可
  3. 只需說明學生其實能通過，不必處理號外
  4. 因為報社後來訂正，所以 07:05 的重開敘事自動成真
答案: A

解析必須同時處理錯誤範圍與不存在的狀態轉換；只改一個量詞仍會保留報社製造的因果敘事。

LU-L022. 目前最能承受反證的結論是？12 分

題目材料
【人里曆】第九日酉時起霧，戌時鐘停。
【月都式記錄】同一夜標作第十日；鐘停早於起霧半刻。
【慧音講義抄】里曆換日於子時；月都值班簿換日於酉時。
【鐘樓維修簿】「霧先至」一行以較新的墨補寫。
  1. 月都記錄一定偽造，因為日期比人里快
  2. 換日規則可解釋九日／十日差異；但霧與停鐘先後仍衝突，且「霧先至」補寫不能作獨立證據
  3. 較新的墨代表較準確的觀察
  4. 兩份記錄日期不同，所以不可能描述同一夜
答案: B

解析先把可由制度解釋的日期差與真正的事件次序衝突分開；補寫來源依附於爭議本身，不能打破平手。

LU-L033. 在不替規章補寫新條文的前提下，哪一判讀最嚴謹？12 分

題目材料
【校規 v3.1】「缺席」指學生未進入排定教室。
【教務補充 v3.1b】教室因境界移動時，以教師所在空間為準。
【紫的通知】本日教室位於「出席與缺席之間」，教師仍在原講台。
【門禁】學生甲進入原教室；空間標籤顯示「非排定教室」。
  1. 教師沒有移動，表示教室也絕不可能移動
  2. 只看空間標籤，學生甲必然缺席
  3. v3.1b 把教師所在空間指定為教室，故甲有出席依據；但「排定教室」與「教室」是否同義仍是版本漏洞
  4. 紫使用引號，所以所有門禁資料作廢
答案: C

解析補充條文提供有利於出席的操作定義，但主條文的「排定」限定尚未被明確覆蓋；嚴謹答案要保留這個缺口。

LU-M033. 起始出口 A 的最終標籤為何？14 分

題目材料
竹林三岔口每天按置換 σ=(A B C) 移動出口標籤；滿月另施加交換 τ=(B C)。今天是滿月後第 5 日，且先施加每日置換五次，再施加滿月交換一次。起始出口 A 的最終標籤為何？
  1. A
  2. B
  3. C
  4. 無法判斷
答案: B

解析σ⁵=σ²，A→C；再施 τ，C→B。按通常右合成記號易混淆，但題目已明說操作順序，所以答案 B（選項 B）。

LU-C011. 目前最合理的處理順序是？10 分

題目材料
事件：帕秋莉館藏《七曜逆引》離架。
門禁：魔理沙 13:02 入館，15:11 離館；愛麗絲 14:20–14:48。
借閱簿：無借出。
小惡魔：14:35 見書仍在。
魔理沙材料箱：15:20 被拍到有同尺寸藍封面，但無書脊。
結界：14:50–15:05 西窗封鎖失效。
  1. 只調查愛麗絲，因她停留較短
  2. 立即認定魔理沙偷書並刊登號外
  3. 先核對 14:35 後的書架／西窗痕跡與藍封面書脊，再詢問同時段在場者；保留多個假說
  4. 因借閱簿空白，書必然從未離架
答案: C

解析資料縮小了時間窗卻未唯一指向一人；封鎖失效與模糊照片都需要先取得能區分假說的證據。

LU-C022. 哪個判讀同時處理規則類型與資訊更新？10 分

題目材料
規則：研究飛行不得穿越食堂上空；異變處理可走最短安全線。
12:00 食堂煙囪倒流，妖精誤報為火災；12:03 靈夢自神社直飛食堂上空；12:05 確認只是夜雀烤爐；12:07 她改道降落。
報告標題：「巫女公然違反研究飛行禁令」。
  1. 只要最後不是火災，早先所有決策都自動違規
  2. 巫女永遠不受任何校規約束
  3. 妖精誤報使煙囪倒流也沒有發生
  4. 12:03 依當時資訊屬異變處理例外；12:05 後例外理由消失，而 12:07 改道與此相容。原標題把任務類型寫錯
答案: D

解析決策應按當時可得資訊評估，且研究飛行禁令不等同異變處理規則。

LU-C033. 制度上最準確的結論是？10 分

題目材料
三方表決校慶主舞台：神奈子持 4 票、白蓮 3 票、神子 3 票。章程：涉及信仰儀式時，不只需過半，還須至少兩個傳統各有一票贊成。提案只安排守矢儀式；表決 6–4 通過，其中贊成票全來自守矢與兩名無宗派代表。
  1. 提案未滿足跨傳統條件；不是否定多數票存在，而是本案另有構成門檻
  2. 無宗派代表可自動算作任一宗教
  3. 只要增加舞台音量即可補正
  4. 6–4 過半，所以無條件生效
答案: A

解析這是雙重門檻；票數過半不能替代跨傳統支持。

LU-S011. 哪個診斷最符合全部資料？14 分

題目材料
河童水輪每刻資料：
流量 10,10,10,10；落差 5,5,5,5；輸出 80,79,61,60；軸溫 31,32,48,49。
第三刻起轉速感測器韌體由 v2 升 v3；人工轉數記錄未變；拆檢發現葉輪纏有水草。
  1. v3 韌體必然使真實輸出下降
  2. 水草阻塞可同時解釋輸出下降與軸溫上升；韌體更換與故障同時但人工轉數未變，需分開驗證感測偏差
  3. 流量不變，所以機械不可能故障
  4. 只要降回 v2 就能證明沒有水草影響
答案: B

解析物理共變量支持阻塞；版本事件仍需 A/B 校驗，但不能單靠時間重合取代機理。

LU-S022. 下一輪最能分開藥物、月相、順序與自然病程的設計是？14 分

題目材料
月草藥效研究分兩夜：同 12 名患者，滿月夜服藥甲、次月新月夜服藥乙；結果甲較快。所有患者都先甲後乙，且病程通常隨時間自然改善。
  1. 讓患者自己挑月相與藥
  2. 人數加倍但仍全部先甲後乙
  3. 在滿月／新月內把甲乙隨機分配，並把患者隨機成甲→乙與乙→甲兩序列，設洗脫期並盲化判讀
  4. 只研究滿月
答案: C

解析交叉且平衡的因子設計可估計藥物、月相及順序效應；洗脫與盲化處理殘留及判讀偏差。

LU-S033. 哪個後續步驟對「B 的額外成分造成更大爆炸」最具區分力？14 分

題目材料
星光材料來源紀錄：樣本 A「霧雨店後架」；B「香霖堂外界箱」；C「帕秋莉第七櫃」。光譜顯示 A、C 主峰相同，B 多一峰；三者在同咒式的爆炸半徑 A=8.1、B=11.7、C=8.0。儀器在測 B 前未做暗場校正。
  1. 再拍一次 B 的漂亮爆炸
  2. 把 B 改名為「高火力石」
  3. 只比較 A 與 C
  4. 用已校正儀器重測光譜；把 B 分離出的額外峰成分加入 A/C 並做盲化隨機施術，同時保留 B 去除該成分的對照
答案: D

解析先排除儀器假峰，再以添加／去除介入檢驗成分的必要性與充分性。
