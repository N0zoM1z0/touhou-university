01 / GKL-01

幻想鄉語文

閱讀、史料表述、公告與新聞修辭

36 分

L011. 校報先刊出「北側風路已永久修復」，隔日訂正為「河童膠帶仍算臨時修復」。這則訂正最主要補足了什麼？6 分

  1. 報導發布的先後順序，但未修正永久與臨時的差別
  2. 把「永久」換成較保守的語氣，但未改變通行判斷
  3. 維修狀態與採用的判定標準
  4. 河童膠帶的材料名稱，但未說明目前是否可通行
答案: C

解析訂正改變的不是語氣，而是「永久／臨時」的事實判定，讓讀者能正確安排通行與風險。

L022. 讀竹林告示：「看到第二個一模一樣的集合點時不要停，那是上週的。」最合理的閱讀方式是？6 分

  1. 路徑辨識必須同時核對空間位置與所屬時間
  2. 「第二個」表示走過頭，應立即沿原路返回第一個集合點
  3. 「上週的」只是告示更新日期，不影響眼前集合點的身分
  4. 兩個集合點外觀相同，所以應把較晚遇到的那個視為備用點
答案: A

解析告示同時提供空間與時間線索；「相同外觀」不足以證明是同一地點。

L033. 下列哪一句最適合寫進研究現場紀錄？6 分

  1. 第三次鐘響引發小型異變，並造成照明系統故障
  2. 值班者說昨天熄滅更多盞，因此今日情況應屬正常
  3. 東側的燈大概被妖精弄熄了，因為她們向來不可靠
  4. 第三次鐘響後，東側五盞燈中有兩盞熄滅
答案: D

解析它標明時間、方向、總數與變化，可被下一位觀察者核對。

L044. 同一場小型異變，哪個標題最少把推測寫成事實？6 分

  1. 妖怪山工程導致全校時鐘停擺，校方追查責任
  2. 全校時鐘停擺，原因仍在調查
  3. 河童否認修改時間設定，校方因此排除設備問題
  4. 停擺恰逢妖怪山試運轉，工程應是唯一原因
答案: B

解析「停擺」是已知現象，「原因調查中」明確保留未知部分。

L055. 史料寫：「門在而徑亡，客循鈴聲乃至。」其中「亡」最接近下列哪個意思？6 分

  1. 道路消失，已經無法繼續循路前進
  2. 道路暫借給別處使用，旅客需等待歸還後再通行
  3. 道路遭人破壞，因此旅客只能改聽鈴聲前進
  4. 道路自行逃離原處，但仍可沿留下的痕跡追趕
答案: A

解析上下文以門仍在、路徑不可循形成對比，因此是「消失」。

L066. 要把錯誤校務快訊改成可追溯的訂正，哪個順序最完整？①說明影響範圍 ②保留原標題 ③標出錯誤 ④提供正確資訊與時間6 分

  1. ③①②④：先標錯與影響，再回頭保存原文，最後才訂正
  2. ④①③②：立即給新訊息與影響，待事件結束後才保存原文
  3. ②③④①：先留存原文，再標錯、給出帶時間的正訊息與影響範圍
  4. ④②①③：先公布新訊息，再補存原文，最後才說哪裡錯
答案: C

解析先保留原文，才能指出改了什麼；再給正確資訊，最後說明誰受影響。

02 / GKM-02

結界算術

比例、路網、月相週期與彈幕幾何

42 分

M011. 某月相週期以 29.5 日估算。59 日約等於幾個完整週期？7 分

  1. 1.5
  2. 2
  3. 2.5
  4. 1
答案: B

解析59 ÷ 29.5 = 2。

M022. 水輪原型每分鐘輸出由 80 單位提高到 100 單位，增幅是多少？7 分

  1. 40%
  2. 80%
  3. 20%
  4. 25%
答案: D

解析增加 20，以原值 80 為基準：20 ÷ 80 = 25%。

M033. 從博麗門到工房：步行 31 分；步行 6 分到風路站、候車 4 分、風路 12 分、再步行 5 分。選風路可節省幾分鐘？7 分

  1. 6
  2. 8
  3. 4
  4. 5
答案: C

解析風路總時間 6+4+12+5=27 分，節省 31−27=4 分。

M044. 八個方向各放 3 枚等距彈幕，不計中心，共有幾枚？7 分

  1. 24
  2. 27
  3. 11
  4. 16
答案: A

解析8 個方向 × 每方向 3 枚 = 24 枚。

M055. 藥方為每公斤 0.15 單位，受試者質量 48 公斤。總劑量是多少？7 分

  1. 8.0
  2. 32
  3. 6.2
  4. 7.2
答案: D

解析0.15 × 48 = 7.2。單位仍應寫在正式答案中。

M066. 結界鏡映把點 (3, −2) 變成 (−3, −2)。這是關於哪一條線的鏡射？7 分

  1. x 軸
  2. y 軸
  3. y=x
  4. x=−2
答案: B

解析x 座標變號、y 座標不變，是關於 y 軸的鏡射。

03 / GKC-03

幻想鄉共同常識

規則、校園判斷、異變與共同生活

30 分

C011. 一場符卡式交鋒在開始前最不可缺少的是？5 分

  1. 由裁判保管完整規則，參與者只需知道開始訊號
  2. 先指定名稱與退路，第一回合後再依彈幕補寫規則
  3. 公布名稱與回合數，勝負結束方式交由火力較高者決定
  4. 讓雙方確認名稱、規則，以及各自能辨認的退路
答案: D

解析符卡規則使交鋒可辨認、可結束；單純提高火力不能建立規則。

C022. 在霧湖圖書館發現一本會自行飛向窗外的館藏，最合適的第一步是？5 分

  1. 先關窗阻止飛失，事件結束後再憑封面回想是哪本書
  2. 記下書號、通知館員，並先關閉鄰近窗戶
  3. 使用最近的館藏封印壓住書本，再詢問該封印是否相容
  4. 把書移進空展示櫃單獨觀察，暫不驚動館員或其他讀者
答案: B

解析先控制可逆的環境風險並留下識別資訊，再交由熟悉館藏者處理。

C033. 看到河童原型機冒出藍色火花，但說明紙寫著「正常為綠色」，應如何處理？5 分

  1. 停止操作、保留現場，並通知工房值班者
  2. 立即拆除電源與外殼，先消除危險再補拍原始狀態
  3. 隔離機器並把正常火花改記為藍色，等待下一班覆核
  4. 記錄藍色火花後繼續低功率運轉，以確認是否只是新功能
答案: A

解析顏色偏離既定狀態是可觀察的異常；先停機比改寫標準安全。

C044. 新聞標題已造成誤解，作者同時是訂正課教師。最合理的處理是？5 分

  1. 保留原標題並公開作者身分，讓讀者自行判斷是否可信
  2. 公開更正事實，但不提作者身分，以免把訂正變成私人爭議
  3. 公開訂正，並把作者的利益衝突寫進案例紀錄
  4. 先讓校內委員會審查，再以無痕更新取代原標題
答案: C

解析角色身分正是需要可見訂正與利益衝突說明的原因，不是豁免。

C055. 滿月夜前往永遠亭門診，校園詳圖提示本館直廊封閉。應選哪條路？5 分

  1. 沿本館直廊到診療所，因為目的地仍在同一建築群
  2. 依滿月分流，由本館經調劑室前往診療所
  3. 先到昨日的空地等校鐘，再由聲音反推診療所方向
  4. 沿第四盞燈繞過直廊，因為夜間燈號比詳圖更新更快
答案: B

解析滿月管制把門診人流經調劑室分流；第四盞燈不屬於可靠夜間指引。

C066. 八雲紫把教室移到「出席與缺席之間」。學生首先應確認哪一項？5 分

  1. 教師口頭指定哪一側為教室，以該側暫代正式規章
  2. 校園路由器目前把訊號判定在校內還是校外
  3. 課後點名是否把學生記為缺席，再依結果決定位置
  4. 規章中的上課位置與出席定義是否涵蓋這種地址
答案: D

解析這個事件的核心是制度對位置與出席的定義邊界；先讀定義才能判斷漏洞。

04 / GKH-04

文科綜合

歷史、地理、新聞與信仰公共生活

42 分

H011. 三份史料對同一異變日期不一致。最好的歷史研究方法是？7 分

  1. 暫時排除最晚史料，待其日期與前兩份一致再納入
  2. 先統一成同一曆法，再把三個日期平均為事件日期
  3. 比較成文時間、作者位置與各自使用的曆法
  4. 優先採用最早成文者，因為較少受到後世記憶影響
答案: C

解析差異本身是證據；來源條件與曆法能解釋差異如何形成。

H022. 神社、寺院與道觀爭用同一筆公共活動預算。哪個方案最能顯示真正的公共協商？7 分

  1. 公開各方目的、不可讓步處、共同設施成本與仍存異議
  2. 依預估參加人數加權分配，最後公告只列通過的方案
  3. 三方各提完整方案後抽籤，落選者不得再要求共同設施
  4. 先平均分配，要求三方把不同目的調整到相同額度內
答案: A

解析協商不是假裝沒有衝突，而是讓資源、立場與未解決異議可見。

H033. 迷途竹林地圖每天偏移，但永遠亭表門相對穩定。製圖時應如何表示？7 分

  1. 區分固定錨點、條件路徑，並標示每層的更新時間
  2. 只畫每日路徑並每天重印，以免固定錨點造成過度信任
  3. 保留比例尺與表門，把竹林的不確定性統一寫在圖下注記
  4. 把最近測得的路徑畫成實線，表門則只作方向參考
答案: A

解析條件地理需要同時表達穩定程度與資料時效，不能把暫時路徑偽裝成固定。

H044. 慧音的課要求區分「發生、記錄、被允許記得」。這三者的關係最接近？7 分

  1. 公共記憶經長期修正後比當時記錄可靠，可反過來裁定事件
  2. 三者若有兩項一致，就可用多數決還原唯一發生過的版本
  3. 記錄與記憶都可能受到權力、媒介選擇與遺失影響
  4. 最早留下的記錄最接近發生本身，沉默可視為事件不存在
答案: C

解析歷史方法要分析從事件到記錄、再到公共記憶的選擇與損失。

H055. Aya 為搶速報先刊標題、後補查證。這個做法最大的制度風險是？7 分

  1. 讀者可能把後來改寫的標題誤認為另一場新事件
  2. 校內單位可能依錯誤行動，訂正無法自動撤回其後果
  3. 其他報紙可能轉載原標題，卻不保留其最初版面格式
  4. 作者之後必須用課堂時間說明訂正，減少正常授課時數
答案: B

解析事後訂正不能自動撤回已發生的疏散、指控或資源配置。

H066. 博麗神社捐款箱常被搬離校園。若要研究此事，哪個問題最有分析力？7 分

  1. 紅色容器是否比其他顏色容器更常離開原來位置
  2. 最後持有捐款箱的人是否應被視為當時的合法所有者
  3. 移動是否由箱子自行開始，還是由最後接觸者搬動
  4. 神社與大學的所有權、用途和所在規則如何互相衝突
答案: D

解析它把反覆事件放回兩個制度的權利主張，而不是把物件人格化後停止分析。
